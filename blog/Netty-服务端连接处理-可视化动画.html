线程模型说明

入站：accept / read / fireChannelRead读
出站：write / flush / doWrite写
Boss 线程：负责 OP_ACCEPT，并由 Acceptor 提交 child 到 Worker 注册
Worker 线程：I/O 读写与 selector
业务线程：可选 EventExecutorGroup（未指定时默认由 Worker 执行 Handler）
EventExecutorGroup：SINGLE_EVENTEXECUTOR_PER_GROUP=true（默认）时，同一 Channel 在该组内固定一个子 executor
传输范围：仅聚焦 NIO（NioEventLoop / NioSocketChannel）
背压流控：高/低水位触发 channelWritabilityChanged背压
EventLoop：processSelectedKeys → runAllTasks → tailTasks任务
读循环：RecvByteBufAllocator + maxMessagesPerRead 决定 continueReading 批次读
写循环：writeSpinCount 控制 doWrite 尝试次数，写不完才注册 OP_WRITE写
关闭时序：已注册 Channel 通常在 deregister 的 invokeLater 任务中触发 fireChannelInactive / fireChannelUnregistered关闭
接入退避：Acceptor 异常可短暂 setAutoRead(false) 暂停 accept异常
手动读：autoRead=false 时可用 channel.read() 单次拉取读
autoRead/readPending：readPending=false 时 finally 才会 removeReadOp()读
TLS：SslHandler 握手成功后发布 SslHandshakeCompletionEventTLS
TLS 关闭：closeOutbound() 发送 close_notify，SslCloseCompletionEvent 表示关闭结果TLS
半关闭：allowHalfClosure=true 时触发 ChannelInputShutdownEvent / ChannelInputShutdownReadComplete关闭
心跳：IdleStateHandler 超时触发 IdleStateEvent（userEventTriggered）心跳
优雅停机：shutdownGracefully 受 quietPeriod/timeout 约束停机
解码边界：ByteToMessageDecoder 可累计半包并拆分粘包读
ByteBuf 生命周期：入站后由业务侧按语义 release/retain读
术语标识
默认行为：未额外配置时的 Netty 真实路径
示例配置：仅为教学可视化，非默认必需
异常场景：用于展示多种独立异常分支，非单连接必经的连续轨迹
Promise：内部路径常用 voidPromise()，不会触发监听器
关闭分支：未注册/重复 close 可能直接完成 promise，不触发 inactive/unregistered
状态词：ACTIVE/INACTIVE/UNREGISTERED；回调词：channelActive/channelInactive/channelUnregistered
